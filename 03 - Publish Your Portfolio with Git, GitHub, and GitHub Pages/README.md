# Episode 3 - Publish Your Portfolio with Git, GitHub, and GitHub Pages

Move the portfolio into version control and publish it as a website with GitHub Pages.

## What you'll learn

- How commits, branches, merges, and pull requests record changes.
- How a local Git repository connects to a repository on GitHub.
- How to publish a static website with GitHub Pages.
- How to update the site after it is live.

## Try it yourself

1. Open [`index.html`](index.html) and review the portfolio you will publish.
2. Create a GitHub repository and add the portfolio files.
3. Make one change on a feature branch and merge it through a pull request.
4. Enable GitHub Pages and visit the published URL.

## Prompts

```text
Help me publish this portfolio with Git and GitHub. Explain each command in simple
language, use a feature branch for my first change, and stop before any destructive
action.
```

## Expected result

The portfolio files are stored in a GitHub repository, the change history is visible,
and GitHub Pages provides a public website URL.

## Troubleshooting

- If Git is not recognized, install Git and restart the terminal.
- If GitHub Pages shows a 404, confirm that `index.html` is at the configured publishing
  location and that the selected branch is correct.
- If a new commit is not visible on the site, wait for the Pages deployment to finish
  and check the repository's Actions or Pages settings.
