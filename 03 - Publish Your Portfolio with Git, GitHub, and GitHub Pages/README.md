# Episode 3 - Publish Your Portfolio with Git, GitHub, and GitHub Pages

This folder contains the updated portfolio website used in Episode 3 of Build your personal
brand with Copilot. The site adds responsive navigation, light and dark themes, an embedded
resume preview, portfolio sections, and contact links.

Open `index.html` in a browser to preview the site. The mock resume is shared from
[`../common/`](../common/).
