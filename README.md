# Build your personal brand with Copilot 🎓✨

Turn your resume into a portfolio website while learning practical AI and developer tools.
This 10-episode series is made for students, beginners, and anyone curious about building
with GitHub Copilot. No previous developer experience is required.

## Start the series

Watch the series and find all episode resources:

https://aka.ms/student-learning-series-website
